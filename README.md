# Los Doce Pistoleros

Proyecto de Sistemas Electrónicos Digitales, UPM (ETSIDI), curso 2026-2027

## Cómo se juega

1. Se pulsa el botón de inicio y empieza la cuenta atrás.
2. Se apunta a una botella y se aprieta el gatillo (máximo 10 balas).
3. Si el sensor detecta el láser, suman puntos y suena un sonido de acierto. Si no, suena uno de fallo.
4. Al llegar a cero, la pantalla muestra la puntuación final y el récord.
